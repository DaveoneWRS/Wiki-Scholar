# Serververwaltung

:::info Abgelöst
Das frühere Server-Modul gibt es nicht mehr. Es wurde durch die **IT-Dokumentation** ersetzt, die Standorte, Geräte, Netze, Dienste, Verträge, Wartung und Logbuch organisationsweit an einer Stelle führt.
:::

Bestehende Server, ihre Logbucheinträge und Tags wurden bei der Umstellung übernommen. Alte Adressen und Lesezeichen leiten automatisch an die passende Stelle der IT-Dokumentation weiter.

| Früher | Heute |
|---|---|
| Serverliste | [Geräte](/docs/planora/it/geraete) und [Dienste](/docs/planora/it/dienste) |
| Prüfintervall und Versionsprüfung | Wartungsplan **Version prüfen** – siehe [Wartung](/docs/planora/it/wartung) |
| Logbuch je Server | [Logbuch](/docs/planora/it/wartung#logbuch) |
| Tags | [Tags & Flags](/docs/planora/it/uebersicht#tags--flags) |

Einen Überblick über das neue Modul finden Sie unter [IT-Dokumentation – Übersicht](/docs/planora/it/uebersicht).
