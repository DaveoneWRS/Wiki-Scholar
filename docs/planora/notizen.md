# Notizzettel

Die Notizzettel ersetzen den Papierstapel neben dem Telefon. Sie halten kurze Vermerke, Telefonnotizen und kleine ToDos fest, die keine vollständige [Aufgabe](./aufgaben) rechtfertigen. Die Zettel hängen wie Post-its auf einem Board.

## Notiz erstellen

1. **Notizen** in der Seitenleiste öffnen
2. Auf **+ Notiz** klicken und die Art wählen: **Notiz** oder **📞 Telefonnotiz**
3. Titel und Text erfassen
4. Speichern

### Text formatieren

Das Notizfeld ist ein kleiner Editor mit **fett** (Strg+B), *kursiv* (Strg+I) und Links (Strg+K). Links sind auf dem Board anklickbar; nackte Webadressen werden automatisch verlinkt. Beim Kopieren und im Kalender erscheint der Text ohne Formatierung.

Lange Texte werden auf dem Board nach einigen Zeilen gekürzt; **▼ mehr** klappt den vollständigen Text aus. Der Kopier-Knopf **📋** übernimmt immer den ganzen Notiztext in die Zwischenablage.

### Felder einer Telefonnotiz

| Feld | Beschreibung |
|---|---|
| Wer hat angerufen? | Name der anrufenden Person |
| Telefon / Rückruf | Rufnummer für den Rückruf |
| Uhrzeit | Zeitpunkt des Anrufs |
| Weiterleiten an | Zuständige Stelle oder Person, z. B. Sekretariat |
| Notiz | Anliegen in Stichworten |

## ToDo-Notizen

Jede Notiz kann als **ToDo** mit **Fälligkeitsdatum** und Uhrzeit geführt werden. Fällige Notiz-ToDos erscheinen auf Wunsch im [Kalender](./kalender), in der Dashboard-Kachel **Notizen mit Termin** und werden – falls eingerichtet – als Push-Benachrichtigung aufs Handy geschickt. Erledigte Notizen haken Sie direkt auf dem Board ab.

## Ordnen und Wiederfinden

| Funktion | Beschreibung |
|---|---|
| Anheften 📌 | Wichtige Notizen bleiben oben stehen |
| Verschieben ⠿ | Zettel per Drag-and-drop frei anordnen; neue Zettel landen vorne |
| Farbe | Farbliche Markierung des Zettels |
| Kategorien | Eigene Kategorien mit Namen und Farbe anlegen und zuordnen |
| Tags | Freie Schlagwörter; bestehende Tags werden vorgeschlagen |
| Suche | Volltextsuche über Titel und Inhalt |

### Filter

Über die Filterleiste schränken Sie die Liste ein: **Alle**, **Offene ToDos**, **Überfällig**, **Erledigt** und **Anrufe**. Zusätzlich lässt sich nach Kategorie oder Tag filtern; **✕ Filter zurücksetzen** stellt die vollständige Liste wieder her.

## Notizen teilen

Über **👥** an einem Zettel geben Sie eine Notiz an andere Benutzerinnen und Benutzer weiter. Es gibt zwei Wege:

| Weg | Wirkung |
|---|---|
| Gemeinsam bearbeiten | Alle Beteiligten sehen und bearbeiten **dieselbe** Notiz – Änderungen wirken sich sofort bei allen aus |
| Als Kopie senden | Beim Empfänger entsteht eine unabhängige Kopie |

Mit Ihnen geteilte Zettel stehen im Bereich **👥 Mit mir geteilt**. Über **🚪** verlassen Sie eine Freigabe wieder; beim Besitzer bleibt die Notiz erhalten.

:::note
Hat jemand anderes eine geteilte Notiz geändert, während Sie sie bearbeiten, fragt Planora beim Speichern nach, statt die Änderung still zu überschreiben.
:::

## Verlauf

Über **🕘 Verlauf** sehen Sie frühere Stände einer Notiz samt Bearbeiter. Jeder Stand lässt sich wiederherstellen. Der Verlauf wird 90 Tage aufbewahrt.

## Papierkorb

Gelöschte Notizen wandern zunächst in den Papierkorb und lassen sich von dort **wiederherstellen**. Mit **Endgültig löschen** entfernen Sie einzelne Einträge, mit **Papierkorb leeren** den gesamten Inhalt.

:::warning
Endgültig gelöschte Notizen können nicht wiederhergestellt werden.
:::

:::tip
Für die Schul-IT gibt es zusätzlich ein gemeinsames Notizbrett mit Wiedervorlagen – siehe [IT-Dokumentation](/docs/planora/it/uebersicht#notizen--wiedervorlagen).
:::
