# Dashboard

Das Dashboard ist die Startseite nach der Anmeldung. Es bietet eine schnelle Übersicht über aktuelle Vorgänge und wichtige Informationen.

## Übersicht

Das Dashboard besteht aus Boxen in zwei Spalten. Je nach Rolle und aktiven Modulen erscheinen:

| Box | Inhalt |
|---|---|
| WRS - Schulverwaltung | Anzahl ausstehender Freischaltungen (Klassenanmeldungen) mit Link **Zur Freischaltung** |
| Hinweise zum Datenschutz | Allgemeine Datenschutzhinweise |
| Neue Schüler-Ereignisse | Ereignisse, über die Sie benachrichtigt wurden |
| Checklisten | Ihre offenen [Checklisten](./checklisten) |
| Offene Self-Service Aufträge | Anfragen aus den [Selbstservice-Portalen](./selbstservice), die noch bearbeitet werden müssen |
| Gerätereservierungen | Anstehende Reservierungen von Geräten |
| Meine Klassen | Die Ihnen zugeordneten Klassen |
| Notensystem | Arbeitsschritte der Notenerfassung – nur solange die Noteneingabe freigeschaltet ist (siehe [Noten & Zeugnisse](./noten)) |
| Schulferien | Die nächsten Ferientermine |
| Offene Küchenreservierungen | Anstehende Reservierungen der [Schulküche](./schulkueche) (falls Modul aktiv) |
| Aktivierte MagicCards | Schülerinnen und Schüler mit aktivierter MagicCard |
| Geburtstage | Heutige Geburtstage von Schülerinnen, Schülern und Mitarbeitenden |

## Dashboard anpassen

Die Anordnung der Boxen lässt sich persönlich einstellen und wird pro Benutzer gespeichert:

1. Klicken Sie auf **Anordnung anpassen**
2. Verschieben Sie die Boxen per Drag & Drop oder mit den Pfeilen (**Nach oben**, **Nach unten**, **In die andere Spalte**)
3. Blenden Sie nicht benötigte Boxen mit **Box ausblenden** aus
4. Beenden Sie die Bearbeitung mit **Fertig** – die Anordnung wird automatisch gespeichert

Ausgeblendete Boxen finden Sie unter **Ausgeblendete Boxen** und können sie dort wieder einblenden. **Standard wiederherstellen** setzt die Anordnung zurück und blendet alle Boxen wieder ein.

## Benachrichtigungen

Benachrichtigungen werden automatisch angezeigt, wenn:
- Ein Schülerereignis für Sie eingetragen wurde
- Systemupdates verfügbar sind
- Anmeldungen zu genehmigen sind

Schüler-Ereignisse können einzeln geöffnet oder mit **Alle als gelesen markieren** abgeschlossen werden.

## Favoritenleiste

In der linken Seitenleiste können häufig genutzte Seiten als **Favoriten** gespeichert werden:

1. Klicken Sie auf **Favorit hinzufügen**
2. Wählen Sie einen Namen und ein Icon
3. Der Favorit erscheint dauerhaft in der Seitenleiste

Die Reihenfolge der Favoriten kann per Drag & Drop angepasst werden. Über das Benutzermenü oben rechts lässt sich die **Favoriten-Leiste** ein- und ausblenden.

## Navigation

Die obere Navigationsleiste enthält folgende Menüs (je nach Rolle und aktiven Modulen):

| Menü | Inhalt |
|---|---|
| Module | Geräte, Schulbuch (LM), Bibliothek, Klassengeld, Lagerverwaltung |
| AG Modul | Arbeitsgemeinschaften, Zuweisung und Statistik |
| Erziehungsberechtigte | Elternverzeichnis, Eltern ohne SuS und Elternvertretung |
| Wahlmodul | [Fremdsprachenwahl](./listen#fremdsprachenwahl) aus dem Elternportal |
| Notensystem | Noteneingabe, Zwischennoten, Zeugniskonferenz, Konfiguration |
| Checklisten | Eigene und verwaltete Checklisten |
| ILE | Individuelle Lernentwicklung |
| Meine Klassen | Schülerübersicht, WLAN-Freischaltung, Klassenkasse |
| FKL-Verwaltung | [Fachkonferenzen](./fachkonferenzen), Fachschaften, Lernmittel der Fachschaft |
| Klassenverwaltung | Klassenzuweisung, Listen, Klassenlisten |
| Reservierungen | Geräte und Schulküche |
| Stundenplan | Klassen- und Lehrerpläne, Raumübersicht |
| Listen | Auswertungen und Druckvorlagen |
| Sekretariat | On-/Offboarding, Listen, Gastschüler, Schüler im Ausland, Schließfächer, Anmeldungen, Datenimport |
| Org | [Fallmanagement](./fallmanagement) |
| Admin | Systemverwaltung (Administration, Schulleitung bzw. Export-Berechtigung) |

Oben rechts befindet sich die **Schülersuche** für den schnellen Zugriff auf Schülerprofile – mit dem [Quicksearch-Verlauf](./schueler#quicksearch-verlauf) der zuletzt geöffneten Personen.

Im Benutzermenü lässt sich außerdem die **Sprachausgabe** der Scanner ein- und ausschalten.
